# Inanición en SRTF: un proceso largo compite con un flujo continuo de
# procesos cortos (llega uno cada 2 ticks, justo cuando termina el anterior).
#
# - SRTF puro (set_sched SRTF): Largo no obtiene la CPU hasta t=16, cuando
#   se acaba el flujo; si el flujo no terminara, no se ejecutaría nunca.
#   Gantt: [0-2s: Corto_1] -> ... -> [14-16s: Corto_8] -> [16-22s: Largo]
# - Con envejecimiento (set_aging 2, luego set_sched SRTF): la ráfaga
#   efectiva de Largo baja 1 tick por cada 2 de espera y obtiene la CPU en t=8.
#   Gantt: [0-2s: Corto_1] -> ... -> [6-8s: Corto_4] -> [8-14s: Largo] -> ...
#
